# Скачивание программы и публикация установщиков

- `/download/` — общедоступная страница актуальной Windows-сборки, размера файла, описания и SHA-256.
- `/download/installer/` — выдача текущего EXE как вложения, без необходимости входа.
- `/release-admin/` — отдельная страница загрузки и публикации. Доступ имеют только активные суперпользователи (`is_superuser`); роли организации и `is_staff` сами по себе доступа не дают. Для гостей используется существующая форма входа.
- Ссылки скачивания есть на лендинге и в боковой панели CRM. Ссылка управления версиями в боковой панели видна только суперпользователям.

Загрузка: указать версию `X.Y.Z`, выбрать готовый установщик `.exe` до 512 МБ, при необходимости добавить описание и нажать «Загрузить и опубликовать». Версия должна соответствовать фактической сборке. Файл проверяется по расширению, размеру и заголовку MZ; это не проверка цифровой подписи или антивирусное сканирование.

Хранилище задаётся `APP_INSTALLER_DIR`; по умолчанию это `crmserver/releases/installers/`. Файлы получают случайные имена, `current.json` атомарно указывает на текущую версию. Предыдущие файлы сохраняются, начатое скачивание не прерывается. Хранилище исключено из Git, поэтому при развёртывании его нужно перенести отдельно либо загрузить установщик через админку. Оно должно быть доступно серверу для записи и постоянно храниться между развёртываниями; при нескольких экземплярах сервера нужен общий том. Прямую публичную раздачу каталога не настраивать. Лимит тела запроса и таймаут reverse proxy должны позволять загрузку установщика.

19.09.2026 установщик `dist/AgroSmenaCRM-0.1.2-Setup.exe` пересобран с новым логотипом `assets/crm-logo.png` (54 042 386 байт), копия в локальном хранилище скачиваний обновлена. В EXE приложения и установщика проверены встроенные ресурсы всех семи размеров иконки. Сборка выполнена с `-SkipSmokeTest`; программа, сайт, тесты и миграции не запускались. Новая схема БД не требуется. Публикация полного установщика не изменяет каталог патч-обновлений `/api/app/update/`.
